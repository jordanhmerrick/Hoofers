# Hoofers — test rig 0.2

Playable prototype of the Hoofers loop: swing, watch it fly, walk the real-world
distance it earned you, swing again, hole out.

Deliberately schematic. No art — the point is whether the swing feels good and
whether the walk is worth it.

Needs an https origin and a top-level page (not an iframe) for the iPhone motion
sensor to count steps.
